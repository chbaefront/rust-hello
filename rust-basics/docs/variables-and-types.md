# Rust 변수와 기본 타입

Rust의 변수는 기본적으로 불변이며, 모든 값은 컴파일 시점에 결정되는 타입을 가집니다. 실행 가능한 전체 예제는 [`src/variables_and_types.rs`](../src/variables_and_types.rs)에 있습니다.

## `let` 변수

지역 변수는 `let`으로 선언합니다. Rust 변수는 기본적으로 불변이므로 선언한 값을 다시 대입할 수 없습니다.

```rust
let language = "Rust";
// language = "Go"; // 불변 변수이므로 컴파일 오류
```

값을 변경해야 한다면 `mut`를 추가합니다.

```rust
let mut score = 10;
score += 5;
```

`mut`는 같은 변수에 새 값을 대입하는 것이므로 변수의 타입은 바꿀 수 없습니다.

```rust
let mut count = 1;
count = 2;
// count = "two"; // 기존 타입은 정수이므로 컴파일 오류
```

초기값을 나중에 지정할 수도 있지만, 사용하기 전에는 반드시 값이 초기화되어 있어야 합니다. 여러 실행 경로가 있다면 컴파일러는 모든 경로에서 초기화되는지 검사합니다.

```rust
let result: i32;
result = 10;
println!("{result}");
```

## 섀도잉

같은 이름으로 `let` 변수를 다시 선언하면 이전 변수를 가리는 섀도잉(shadowing)이 발생합니다.

```rust
let spaces = "   ";
let spaces = spaces.len();
```

두 번째 `spaces`는 새로운 변수이므로 첫 번째 변수와 다른 타입을 가질 수 있습니다. 이는 기존 변수의 값만 변경하고 타입은 유지하는 `mut`와의 중요한 차이입니다. 내부 스코프에서 섀도잉한 변수는 해당 스코프가 끝나면 사라지고 바깥 변수가 다시 보입니다.

## `const` 상수

상수는 `const`로 선언합니다.

```rust
const MAX_POINTS: u32 = 100_000;
const SECONDS_PER_HOUR: u32 = 60 * 60;
```

| 구분 | `let` | `const` |
| --- | --- | --- |
| 가변성 | `mut`로 변경 가능 | 항상 불변 |
| 타입 표기 | 추론 가능 | 반드시 명시 |
| 값 | 런타임에 계산 가능 | 컴파일 시간에 계산 가능해야 함 |
| 선언 위치 | 주로 함수 내부 | 전역·모듈·함수 내부 모두 가능 |
| 이름 관례 | `snake_case` | `SCREAMING_SNAKE_CASE` |
| 섀도잉 | 가능 | 같은 스코프에서 불가능 |

상수는 프로그램이 실행되는 동안 변하지 않는 의미 있는 값에 이름을 부여할 때 사용합니다. 단순히 현재 값만 바뀌지 않아야 하는 지역 데이터라면 불변 `let` 변수가 더 적합합니다.

## 타입 추론과 타입 표기

Rust 컴파일러는 초기값과 사용 방식을 바탕으로 타입을 추론합니다.

```rust
let count = 10;       // 기본 정수 타입 i32
let ratio = 2.5;      // 기본 부동소수점 타입 f64
let parsed: u32 = "42".parse().expect("숫자 변환 실패");
```

여러 타입이 가능해 컴파일러가 하나를 결정할 수 없거나 원하는 타입이 따로 있다면 `변수명: 타입` 형식으로 명시합니다.

## 스칼라 타입

스칼라 타입은 하나의 값을 나타냅니다. Rust의 기본 스칼라 타입은 정수, 부동소수점, 불리언, 문자입니다.

### 정수

| 크기 | 부호 있음 | 부호 없음 |
| --- | --- | --- |
| 8비트 | `i8` | `u8` |
| 16비트 | `i16` | `u16` |
| 32비트 | `i32` | `u32` |
| 64비트 | `i64` | `u64` |
| 128비트 | `i128` | `u128` |
| 아키텍처 크기 | `isize` | `usize` |

부호 있는 정수는 음수와 양수를, 부호 없는 정수는 0과 양수만 표현합니다. `isize`와 `usize`의 크기는 실행 환경이 32비트인지 64비트인지에 따라 달라집니다. 컬렉션의 인덱스에는 주로 `usize`를 사용합니다.

정수 리터럴은 여러 표기법을 지원합니다.

```rust
let decimal = 98_222;
let hexadecimal = 0xff;
let octal = 0o77;
let binary = 0b1111_0000;
let byte = b'A'; // u8만 가능
```

정수 타입의 표현 범위를 벗어나는 연산은 오버플로입니다. 디버그 빌드에서는 패닉이 발생할 수 있으며, 의도적인 오버플로 계산에는 `wrapping_*`, `checked_*`, `overflowing_*`, `saturating_*` 메서드를 명시적으로 사용합니다.

### 부동소수점

Rust의 부동소수점 타입은 `f32`와 `f64`입니다. 기본 타입은 일반적으로 정밀도가 더 높은 `f64`입니다.

```rust
let x = 2.5;      // f64
let y: f32 = 3.5;
```

부동소수점은 근삿값으로 저장되므로 금액처럼 정확한 소수 계산이 필요한 데이터에는 별도의 표현 방법을 고려해야 합니다.

### 불리언

`bool`은 `true`와 `false` 두 값만 가지며 조건문에서 사용됩니다.

```rust
let is_learning = true;
let is_finished: bool = false;
```

### 단일 문자: `char`

`char`는 작은따옴표로 표현하는 스칼라 타입입니다. 하나의 유니코드 스칼라 값을 저장하며 메모리에서 항상 4바이트를 사용합니다. 따라서 영문자뿐 아니라 한글과 이모지도 표현할 수 있습니다.

```rust
let latin = 'R';
let korean = '러';
let emoji = '🦀';
```

`char`는 "화면에 보이는 글자 한 칸"과 항상 일치하지는 않습니다. 일부 글자는 여러 유니코드 스칼라 값이 결합되어 표현되기 때문입니다. 또한 UTF-8 문자열 안에서 `'R'`, `'러'`, `'🦀'`가 차지하는 바이트 수는 각각 다르지만, `char` 값 자체의 크기는 모두 4바이트입니다.

### 문자열 리터럴은 왜 `&str`인가

큰따옴표로 표현하는 `"Rust"`는 단일 값이 아니라 여러 UTF-8 바이트가 연속된 문자열입니다. 따라서 하나의 유니코드 스칼라 값을 나타내는 `char`가 될 수 없습니다.

```rust
let character: char = 'R';
let text: &str = "Rust";
```

`str`은 유효한 UTF-8 바이트의 연속 영역을 나타내는 기본 문자열 슬라이스 타입입니다. 문자열의 길이는 실행 중에 달라질 수 있으므로 `str` 자체는 컴파일 시점에 크기를 알 수 없는 동적 크기 타입입니다. 일반적으로 `str`을 값으로 직접 사용하지 않고 참조인 `&str`로 사용합니다.

`&str`은 문자열 데이터의 시작 위치와 바이트 길이를 가진 빌린 뷰입니다. 문자열 리터럴의 데이터는 컴파일된 프로그램 바이너리의 정적인 영역에 포함되고 프로그램이 실행되는 동안 계속 유효합니다. 따라서 문자열 리터럴의 정확한 타입은 정적 수명을 가진 `&'static str`이며, 보통은 수명을 생략해 `&str`로 표현합니다.

```rust
let language: &'static str = "Rust";
```

여기서 `&`는 문자열 데이터를 소유하는 것이 아니라 이미 존재하는 데이터의 일부를 바라본다는 뜻입니다.

### `&str`과 `String`의 차이

`&str`과 `String`은 모두 유효한 UTF-8 문자열을 다루지만 소유권과 변경 가능성에 차이가 있습니다.

| 구분 | `&str` | `String` |
| --- | --- | --- |
| 역할 | 기존 문자열 데이터를 빌린 슬라이스 | 문자열 데이터를 소유하는 컬렉션 |
| 데이터 소유권 | 없음 | 있음 |
| 길이 변경 | 불가능 | `mut`이면 가능 |
| 대표 생성 방식 | 문자열 리터럴, `String`의 슬라이스 | `String::from`, `.to_string()` |
| 전달 후 사용 | 참조이므로 일반적으로 계속 사용 가능 | 값으로 전달하면 소유권이 이동할 수 있음 |
| 주요 용도 | 문자열을 읽기 위한 함수 매개변수 | 문자열을 저장하거나 수정해야 할 때 |

`String`은 힙에 저장된 UTF-8 데이터를 소유합니다. `String` 값 자체는 데이터의 위치, 현재 길이, 할당 용량을 관리하며 `mut`으로 선언하면 내용을 추가하거나 제거할 수 있습니다.

```rust
let mut owned = String::from("Rust");
owned.push_str(" language");
```

`String` 전체 또는 일부를 빌리면 `&str`로 사용할 수 있습니다.

```rust
let owned = String::from("Rust language");

let whole: &str = &owned;
let first_word: &str = &owned[..4];
```

`&String`은 필요한 경우 자동 역참조 변환을 통해 `&str`로 변환됩니다. 따라서 문자열을 읽기만 하는 함수는 `&String`보다 `&str`을 매개변수로 받는 편이 유연합니다. 그러면 문자열 리터럴과 `String`을 모두 전달할 수 있습니다.

```rust
fn print_text(text: &str) {
    println!("{text}");
}

let borrowed = "literal";
let owned = String::from("owned");

print_text(borrowed);
print_text(&owned);
```

반대로 `&str`의 내용을 소유해야 한다면 `String::from(text)` 또는 `text.to_string()`으로 `String`을 만듭니다.

```rust
let borrowed: &str = "Rust";
let owned: String = borrowed.to_string();
```

### 문자열을 인덱스로 접근할 수 없는 이유

Rust 문자열은 UTF-8이므로 문자마다 바이트 길이가 다를 수 있습니다. 예를 들어 `"Rust"`의 `R`은 1바이트지만 `"러스트"`의 각 한글은 3바이트입니다. 따라서 `text[0]`이 첫 번째 바이트인지 첫 번째 유니코드 스칼라 값인지 의미가 모호하며, 바이트 중간을 잘라 유효하지 않은 UTF-8을 만들 수도 있습니다.

그래서 `String`과 `&str`은 정수 인덱스 접근을 제공하지 않습니다. 필요에 따라 다음 반복자를 선택합니다.

```rust
let text = "러스트";

for character in text.chars() {
    println!("{character}");
}

for byte in text.bytes() {
    println!("{byte}");
}
```

- `.chars()`: 유니코드 스칼라 값 단위로 순회
- `.bytes()`: UTF-8 바이트 단위로 순회

사람이 인식하는 글자 단위인 그래핌 클러스터가 필요하면 표준 라이브러리만으로는 충분하지 않을 수 있으며 관련 유니코드 라이브러리를 사용해야 합니다.

## 복합 타입

복합 타입은 여러 값을 하나의 타입으로 묶습니다. 기본 복합 타입에는 튜플과 배열이 있습니다.

### 튜플

튜플은 서로 다른 타입의 값을 고정된 개수로 묶을 수 있습니다.

```rust
let person: (&str, u32, bool) = ("Ferris", 8, true);

let (name, age, active) = person; // 패턴 분해
let first = person.0;             // 인덱스 접근
```

값이 없는 빈 튜플 `()`은 유닛(unit) 타입이며, 값을 반환하지 않는 함수의 반환값으로 사용됩니다.

### 배열

배열은 같은 타입의 값을 고정된 길이로 저장합니다. 배열 데이터는 스택에 저장됩니다.

```rust
let numbers: [i32; 5] = [1, 2, 3, 4, 5];
let repeated = [3; 4]; // [3, 3, 3, 3]

let first = numbers[0];
```

배열은 길이가 타입의 일부이므로 `[i32; 3]`과 `[i32; 5]`는 서로 다른 타입입니다. 실행 중 길이가 변해야 한다면 표준 라이브러리의 `Vec<T>`를 사용합니다. 배열의 유효 범위를 벗어난 인덱스에 접근하면 프로그램이 패닉을 발생시켜 잘못된 메모리 접근을 방지합니다.

## 기본 타입과 소유권

여기서 다룬 정수, 부동소수점, `bool`, `char`와 그 값들로만 구성된 튜플·배열은 일반적으로 `Copy`가 구현되어 있습니다. 다른 변수에 대입해도 소유권이 이동하지 않고 값이 복사됩니다.

`String`, `Vec<T>` 같은 표준 라이브러리 타입은 언어의 기본 스칼라 타입이 아니며 힙 데이터를 소유하므로 대입 시 소유권 이동이 발생할 수 있습니다. 자세한 내용은 [소유권과 빌림](소유권과빌림.md)을 참고합니다.
